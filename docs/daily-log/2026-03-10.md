## 작업 내용
- `index.html` 수동 토너먼트 옵션 라벨을 `건강식 위주`로 변경
- 옵션 hover/focus 시 `저칼로리, 저탄고지, 영향균형 등 반영` 툴팁이 뜨도록 UI 추가
- 건강식 우선 정렬 배열을 요청한 순서 기준으로 전면 교체
- 건강식 정렬 활성화 토스트 문구를 `건강식 위주 정렬을 적용했어요`로 조정
- 건강식 체크를 해제하면 메뉴판이 다시 랜덤 순서로 한 번 섞이고, 해제 상태에서는 그 순서를 유지하도록 로직 수정
- 건강식 토글 on/off 때 1군~3군의 기존 선택 개수는 유지하면서, 선택된 메뉴 자체를 현재 모드 기준(건강식 우선 / 랜덤)으로 다시 뽑도록 재동기화 로직 추가
- `사용 방법` 카드는 웹에서 기존처럼 좌우 카드 전체 높이를 유지하되, 내부 헤더 패딩과 제목 여백만 줄여 상하 공간이 글자 크기에 더 맞도록 보정
- 애드센스 신청 준비를 위해 메인 페이지에 서비스 소개, 건강식 기준 안내, 운영자/문의 정보, 공통 푸터 링크를 추가
- `about.html`, `how-it-works.html`, `privacy.html`, `contact.html` 정적 페이지를 추가해 소개/이용안내/정책/문의 문서를 분리
- `robots.txt`, `sitemap.xml`, `ads.txt`(퍼블리셔 ID 입력 전 안내용) 파일을 추가
- 정적 페이지 공통 스타일 파일 `site-pages.css`를 추가
- 모바일에서 토너먼트 시작 시 이전 설정 스크롤 위치와 무관하게 `VS` 중심으로 자동 스크롤해 두 메뉴가 함께 보이는 지점으로 이동하도록 수정
