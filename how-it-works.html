머먹지!?는 토너먼트를 중심으로, 필요한 설명 페이지가 그 결정을 돕는 구조입니다.

메뉴 토너먼트 바로 시작 메뉴 사전 둘러보기

토너먼트 사용 흐름

  • 자동 토너먼트에서는 4강부터 128강까지 원하는 규모를 고릅니다.
  • 수동 토너먼트에서는 원하는 메뉴를 직접 체크하거나 군별 비중을 조절합니다.
  • 건강식 위주 체크를 켜면 1군~3군 선택 메뉴를 현재 기준에 맞게 다시 맞춥니다.
  • 결과가 나오면 지도와 배달 앱으로 바로 연결할 수 있습니다.

콘텐츠를 먼저 볼 때

메뉴 자체를 잘 모르면 메뉴 사전으로, 두 메뉴 사이에서 갈리면 메뉴 비교로, 오늘 상태가 먼저 중요하면 상황별 추천으로 들어간 뒤 토너먼트로 돌아오면 됩니다.
